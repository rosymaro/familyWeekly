# familyWeekly
One place for the whole family's weekly schedule. Organize routines, manage special events, and stay on track with customizable widgets and reminders.

아이마다 다른 주간 시간표를 홈 화면 위젯으로 보고, 특이 일정은 포스트잇처럼 덧붙이고, 일정마다 알림을 받는 안드로이드 앱.

프로젝트 스펙과 작업 규칙은 `agent/` 폴더를 참고하세요.

- `agent/SPEC.md` — 기능 스펙, Phase 계획, 진행 상황
- `agent/DESIGN.md` — 디자인 토큰, 상태 표현 규칙, 디자이너 브리프
- `agent/PROMPTS.md` — Phase별 Claude Code 지시문
